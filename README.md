# SIGMOID Challenges — Code and Evidence

This repository contains reproducible solutions and supporting evidence, organized by country.

| Country | Challenge | Source, data and evidence |
|---|---|---|
| 🇪🇪 **Estonia** | This Data Is Perfect! — fraud pipeline audit | [Estonia/](Estonia/README.md) |
| 🇫🇮 **Finland** | Pipes, Leaks and the Graph Underneath — route network reconstruction | [Finland/](Finland/README.md) |
| 🇳🇴 **Norway** | Nisse's Bad Swap — handwritten-digit label repair | [Norway/](Norway/README.md) |

Each country folder includes its own README explaining the solution, evidence, and reproduction steps. When a challenge asks for a GitHub link, submit the specific country folder rather than the repository root.

Source datasets are provided by the SIGMOID challenge organizers.
